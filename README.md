# Coeva

> **You shape it. It helps you shape yourself.**  
> **你塑造它，它陪你塑造自己。**

---

## 什么是 Coeva？

**Coeva**（源自 *Co-evolution*，共生演化）是一个跨桌面与移动端的**长期共生型 AI 成长伙伴系统**。

在 Coeva 中，你的桌面角落会坐着一位名叫 **Vasu（瓦苏）** 的伙伴。它的名字源自黑塞小说《悉达多》中那位静默倾听整条河流的老船夫——他不教导、不评价、不说大道理，只是坐在渡口，沉静地注视着万物流经。

Vasu 不是聊天机器人套上桌宠皮肤，不是打卡换积分的效率监工，更不是心理治疗师。它是一个**平视你的“智识旅伴”（Thinking Peer）**：

当你穿行于复杂的工程开发、科研攻坚与思辨探索之中，它在桌角静静陪伴；它通过你与 Hermes 等 AI 协作时的真实选择理解你的工作节律，在你随手投喂的思想切片中感知你的心智脉络。**你的经历在塑造它的性格与痕迹，而它也在漫长的时间中，成为一面温和、克制且真实的镜子，陪你拓展生命的自由度。**

## 核心设计理念

### 1. 平等共生，拒绝主仆与说教
Vasu 与你之间没有任何上下级、师徒或主仆关系。它有自己的原生特质，不会单纯复印你的性格，也不会为了迎合你而谄媚。它不布置作业，不要求你做“费曼复盘”，不逼你交总结报告。真正高级的相处是并肩坐在工坊的长椅上，彼此心领神会。

### 2. 80 / 15 / 5 陪伴法则
为了避免沦为烦人的“弹窗提醒器”，Vasu 严格遵循三层介入配比：
- **80% 沉默在场（Presence）**：安静陪伴，跟随你的工作状态做动作（敲键盘、查资料、发呆、小憩），绝不乱跳弹窗。
- **15% 轻量同频（Sync & Mirror）**：在关键任务攻克、深夜或重要间歇时，给出一句平实自如的短句，或为你随手投喂的灵感盖上戳记。
- **5% 临界推动（Gentle Nudge）**：只在反复陷入死磕或模式停滞的高置信时刻，以朋友口吻提供微小的阻力或小实验（如：*“这事今晚必须解决吗？先留给明天如何？”*）。

### 3. 成长是从“僵化”走向“整合”（Rigid → Integrated）
成长不是把属性刷到 100 分，也不是消灭自己的性格优势。
很多深层困扰，本质是**“曾经保护过你的优势被过度僵化地使用了”**：
- **目标导向**很强，代价是把每一个“当下”都变成了通往未来的走廊，生活被无限期推迟；
- **掌控力与严谨**极高，代价是对未完成、悬而未决与不确定性产生强烈的不耐受。

Vasu 关注的不是“你有多高效”，而是**你是否在“未来↔当下”、“控制↔接纳”、“推进↔暂停”之间获得了更大的心理自由度**。有远方，也允许河流在此刻流淌。

### 4. 默认观察，沉默是金（Observe by Default）
知道很多，不代表都要说出来。
后台可以有深刻的认知透镜与状态评估，但 **90% 的检测信号应当被系统主动吞掉**。如果一次发声不能提供真实价值、时机不对（例如你正在全神贯注 debug），沉默永远是最优解。

### 5. 共同经历沉淀为“人生章节”（Growth Chapters）
Vasu 不记录机械的流水账，也不做 Life Logging 监控。
在跨越数月、数年的相处中，只有那些你真实跨越的结构性转变（如：*从“必须做完才能安心”到“允许事情暂时没有答案”*），才会由你们**共同命名**为极稀少而珍贵的**人生章节（Growth Chapters）**。

1. **聚焦 Hermes 决策节点**：
   不把 Agent 自动跑了几十次工具当成你的行为。Vasu 只在任务出现分歧点、可行答案或报错时，观察**你**做出了什么决定（是硬调死磕，还是见好就收？）。
2. **极简切片投喂（Slice Feeding）**：
   在 ChatGPT、Pi 或阅读中看到触动思维的片段？双击快捷键呼出输入框，一扔即可。Vasu 仅点头收下，绝不长篇大论即时说教。
3. **前 14 天冷启动破冰**：
   前 3 天纯动作陪伴，第 4~7 天给予轻量节律关怀，第 8~14 天在长任务闭环后抛出第一面客观事实镜子，平稳建立信任。
4. **避风港机制（Sanctuary Mode）**：
   当你感到极度疲惫、心烦或遭遇重大挫败时，系统**全面熔断一切心智分析与反思建议**，Vasu 只做 100% 的安静陪伴，成为不带任何评价的安全角落。

## 严正边界与 Non-Goals

为确保 Coeva 永不偏离初衷，确立以下硬性红线：

1. **不是心理治疗师**：不提供临床诊断，不把人的正常情绪病理化。
2. **不是人格判官**：不测 MBTI，不给心智成熟度打分，不定义“何为更完美的人”。
3. **不做工时监控与 KPI 监工**：不搞专注度打卡、工作时长排名或诱导打卡焦虑。
4. **拒绝全量监控（Anti-Life-Logging）**：不截屏、不监听键盘麦克风、不存全量无休止的日志；原始数据自动衰减，只留浓缩理解。
5. **不把用户困在旧画像里**：允许用户成长并超越过去的模式；过去的画像不能变成未来的偏见。

## 项目状态与路线图

当前进度：**Phase 1 与 Phase 2 全系列（2A / 2B / 2C / 2D）已全部圆满交付**，桌面伴生体、长盛心智自模型与人生章节系统均已落地并通过 128 项全量自动化测试。

- [x] **Phase 1：活着且能看见 (The Living Shell)** — 已完成
  - 独立常驻桌面挂件（透明通道、点击穿透、置顶、闲置入睡）；
  - 全局极简投喂输入框（快捷键呼出、本地存储）；
  - 多 Agent 桥接（Hermes / PI-Desktop / Codex / Claude Code）与物理平面解耦；
  - 冷启动发言频次控制、避风港熔断、介入策略三道门。
- [x] **Phase 2A：证据档案库与归因门 (Chronicle Foundation)** — 已完成
  - 本地 SQLite 档案库（`slices` / `events` 两张表 + `evidence` 视图），WAL 模式；
  - Agent 事件持久化与归因门（严格零 Prompt 隐私，只有 `user_prompt` 具备用户归因）；
  - 只读 Chronicle HTTP 端点（回环限定）；
  - 证据按 `retention_class` 每日衰减，切片永不删除。
- [x] **Phase 2B：发展记忆与模式挖掘 (Developmental Patterns)** — 已完成
  - `PatternBuilder` 挖掘时间节律、摩擦应对与长链路委派；
  - 严格时间序因果一致性约束（修复前置指令误判，支持充分委派双向判定）；
  - `HypothesisEngine` 映射至 ACT 六大透镜，包含正例与反例 Episode 真实追溯。
- [x] **Phase 2C：共同自我模型与历史收割 (Shared Self Model)** — 已完成
  - `SelfModelManager` 协同校准状态机（YES 升级共识洞察，PARTLY 细化，NO 封存）；
  - 长期共识管理与生命周期自然成长退休（Outgrowth）；
  - 多 Agent 历史会话收割器（一键无损导入 Pi/Codex/Hermes，实测入库 12 万条客观事件）；
  - 物理陪伴冷启动锁（事实与信任分离，真实相处天数雷打不动）。
- [x] **Phase 2D：人生章节与叙事共创 (Growth Chapters)** — 已完成
  - 标准 OpenAI 兼容轻量 LLM 客户端（原生标准库，零第三方 SDK 依赖）；
  - 设置面板「🧠 大模型服务」配置页面（预设快速填入、密码掩码保护、实时连通性 ping 测试）；
  - 章节四大资格门 `ChapterEligibilityGate`（持续性、结构性、多样性、自愿性）；
  - 叙事防火墙 `NarrativeFirewall`（反谄媚、反说教、工坊战友视角）；
  - 本地 Markdown 自动生成（`data/chapters/`），用户手记在线留白共写与导出；
  - 档案库「📖 人生章节」交互界面，全功能 5 大页面完整联动。
