# Vasu 生产契约 · Phase 1

本规范只锁定 Vasu 的形象、素材边界和动画语义；尚未批准任何动画帧。Vasu 是与用户一起生活的小河獭，有自己的节律，不是用户的仆从、吉祥物或 Agent 进度指示器。桌面表现仍由 Growth Core 的低频控制决策驱动。

## 1. 参考优先级与身份锁

1. [`vasu-canonical.png`](../../../assets/vasu/reference/vasu-canonical.png)（1254×1254，透明）：**最高优先级的身份权威**。锁定脸型、头身比例、暖棕皮毛、奶油色口鼻与胸腹、小圆耳、粗实河獭尾、四肢和整体轮廓。其正面偏三分之四的坐姿及尾巴位于画面右侧是这张图的构图，不自动规定所有侧面动作的尾巴位置。
2. [`vasu-companion-board.png`](../../../assets/vasu/reference/vasu-companion-board.png)（1536×1024）：**次级语义与美术方向**。提供安静观察、轻微好奇、休息、河流与石头等情绪、动作和环境线索；板上的各个小图、道具、场景、文字和 UI 不是独立的几何、配色或永久装束权威。
3. [`vasu-pixel-master-64.png`](../../../assets/vasu/reference/vasu-pixel-master-64.png)（64×64，透明）：**小尺寸像素实现参照**。用于核对轮廓、口鼻胸腹分区、眼耳和尾巴在 64×64 下是否仍能辨认；若与主图形体不一致，服从主图。

任何参考冲突均按以上顺序解决。角色本体采用温暖、清晰的像素画：自然紧凑的河獭比例、克制的深色小眼、短口鼻和细微而非夸张的嘴部表情。性格为平静、好奇、善于观察、温柔、独立、略带玩心且安静自豪。无永久服饰或配件；禁止动漫大眼、幼态化、夸张常驻笑脸、眼镜、连帽衫、人类发型、程序员道具、服侍姿态、过度弹跳、随意加道具，以及跨行动画的脸、毛色和轮廓漂移。

方向动作以**朝右**为原始绘制方向。朝左优先在已审定的朝右行上逐帧水平镜像，保留帧顺序；只有确认镜像不会改变不对称特征、光照或动作含义时才执行，否则单独制作朝左行。

## 2. 素材目录与交付边界

```text
assets/vasu/
  reference/                  已提供的三张参考图；只读身份来源
  production/                 后续阶段创建，保存 hatch-pet 工作清单与中间产物
  core/                       后续阶段创建：Codex 兼容 pet.json、spritesheet.webp
  extended/                   后续阶段创建：Coeva 专有动画，独立于 Codex 图集
  qa/                         后续阶段创建：接触表、动作预览与验证结果
```

本轮只新增此规范，不创建空占位目录、图集、动画行或安装包。未来 `core/` 的发布副本分别置于 Codex 的 `${CODEX_HOME}/pets/vasu/` 和现有 Coeva 运行时读取的 `assets/pets/vasu/`；后者还需在宠物选择入口接入。`extended/` 不占用 Codex 图集的 9 行，也不私自扩展 `pet.json` 格式。制作时以 `reference/vasu-canonical.png` 为权威，不用重新生成的 base 图覆盖身份定义。

## 3. Codex 兼容核心动画

hatch-pet 的固定图集为 1536×1872、8 列 × 9 行，每格 192×208，背景透明，未用格必须完全透明。行号、帧数与时长以 hatch-pet 的 `references/animation-rows.md` 为准；以下锁定 Vasu 的动作解释。

| 行 | 状态 | 帧 | Vasu 表达 |
| ---: | --- | ---: | --- |
| 0 | `idle` | 6 | 安静呼吸、偶尔眨眼，首帧也适合作为减少动态效果的静态形象。 |
| 1 | `running-right` | 8 | 朝右移动的自然步态；是拖拽移动语义，不是持续兴奋奔跑。 |
| 2 | `running-left` | 8 | 朝左移动；先审查第 1 行能否安全逐帧镜像。 |
| 3 | `waving` | 4 | 短促、克制的抬爪招呼，随后回到平静姿态。 |
| 4 | `jumping` | 5 | 小幅度的自然跃起与落定，不做夸张弹跳。 |
| 5 | `failed` | 8 | 短暂失落或困惑；不把工具失败解释为 Vasu 或用户的失败。 |
| 6 | `waiting` | 6 | 耐心等待用户输入的轻微关注姿态，不做恳求或服侍动作。 |
| 7 | `running` | 6 | 专注的思索或观察；这是任务进行语义，**不是**脚步奔跑或写代码。 |
| 8 | `review` | 6 | 稍微倾头、凝视或眨眼的细致观察；不新增放大镜、纸张或 UI 道具。 |

这些是**资产兼容状态**，不授权外部 Agent 事件直接驱动桌面动作。现有 `PetState`/`PetWindow.apply_state()` 与图集行并非一一对应：例如 `SLEEPING` 当前回退 `idle`，`THINKING` 优先 `review`，`WORKING` 优先 `running`。真正的事件到动作策略仍由 Coeva 控制面决定；本轮不改运行时代码或声称所有行已经接入。

## 4. Coeva 专有扩展动画

扩展资产另存于 `assets/vasu/extended/`，按 Coeva 桌面身体契约单独设计与接入；不挤进上述九行。下一阶段的候选仅有 `sleep`（夜间/闲置安睡）、`observe`（安静自主观察）与 `slice-ack`（收到主动投喂切片后的轻微确认）。它们尚未定帧数、接口或触发频率，也不是本轮制作任务。河流、石头与日常场景属于可选的氛围/叙事层，不成为 Vasu 的永久随身道具。

## 5. 生产风险与下一道验收门

- 主图偏正面，缺乏同等权威的纯侧面、背面和步态视图；不能直接把情绪板侧面小图当成形体标准。先审定右向侧身关键姿态，再制作或镜像方向行动画。
- 主图的轻微笑意可保留为温和基线，但不可放大为每一帧的夸张笑脸；情绪板更强的表情、道具与近似办公/程序员场景只提供语义灵感。
- 64×64 参照强调小尺寸辨识，192×208 图集允许更多细节；缩放后需同时检查眼、口鼻胸腹、短耳和粗尾是否仍清楚，并避免色阶或脸型随行漂移。
- Codex 的 `waiting`/`running`/`failed` 是兼容语义，与 Vasu 的独立生活哲学存在张力。生产时保持克制，并在 Coeva 中由控制面限制触发；是否需要独立 `sleep` 等扩展另行确定。
- hatch-pet 定义逐帧时长，而现有 Coeva `AnimationPlayer` 按状态固定 FPS 播放；未来接入需核对动作节奏，不能假定两端预览完全一致。

下一步是先审定 Vasu 的右向站/走姿态与像素比例，再用主图和 64×64 参照按 hatch-pet 规格制作完整的 `idle`、`running-right` 试验行，检查身份与步态。只有试验通过后，才继续其余核心行及扩展动画。
