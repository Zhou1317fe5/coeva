# Vasu 生产契约 · Phase 1

本规范锁定 Vasu 的形象、共处关系、素材边界和动画语义；尚未批准任何动画帧。Vasu 是与用户一起生活的小河獭，有自己的节律，不是用户的仆从、吉祥物或 Agent 进度指示器。

## 1. 参考优先级与身份锁

1. [`vasu-canonical.png`](../../../assets/vasu/reference/vasu-canonical.png)（1254×1254，透明）：**最高优先级的身份权威**。锁定脸型、头身比例、暖棕皮毛、奶油色口鼻与胸腹、小圆耳、粗实河獭尾、四肢和整体轮廓。其正面偏三分之四的坐姿及尾巴位于画面右侧是这张图的构图，不自动规定所有侧面动作的尾巴位置。
2. [`vasu-companion-board.png`](../../../assets/vasu/reference/vasu-companion-board.png)（1536×1024）：**次级语义与美术方向**。提供安静观察、轻微好奇、休息、河流与石头等情绪、动作和环境线索；板上的各个小图、道具、场景、文字和 UI 不是独立的几何、配色或永久装束权威。
3. [`vasu-pixel-master-64.png`](../../../assets/vasu/reference/vasu-pixel-master-64.png)（64×64，透明）：**小尺寸像素实现参照**。用于核对轮廓、口鼻胸腹分区、眼耳和尾巴在 64×64 下是否仍能辨认；若与主图形体不一致，服从主图。

任何参考冲突均按以上顺序解决。角色本体采用温暖、清晰的像素画：自然紧凑的河獭比例、克制的深色小眼、短口鼻和细微而非夸张的嘴部表情。性格为平静、好奇、善于观察、温柔、独立、略带玩心且安静自豪。无永久服饰或配件；禁止动漫大眼、幼态化、夸张常驻笑脸、眼镜、连帽衫、人类发型、程序员道具、服侍姿态、过度弹跳、随意加道具，以及跨行动画的脸、毛色和轮廓漂移。

方向动作以**朝右**为原始绘制方向。朝左优先在已审定的朝右行上逐帧水平镜像，保留帧顺序；只有确认镜像不会改变不对称特征、光照或动作含义时才执行，否则单独制作朝左行。

## 2. 共处关系与动作语言

**自主而相伴（Autonomous, relationally coupled）**：Vasu 有自己的生活线——做有目的的小事、休息、睡觉、玩耍、观察和探索；它也知道用户在场，偶尔会回应、注视、相伴或短暂互动。关系节奏是多数时间安静共处，有时流露对周围的感知，偶尔短暂互动，极少主动发起。用户的活动可以影响 Vasu，却不能直接控制它，也不能被它逐项模仿。**互动是共同生活中的事件，不是默认状态。**Vasu 不是 Agent 状态灯、进度吉祥物、用户动作的镜像、索取注意的宠物或常开助手。

- **安静地同处**：用户工作时，Vasu 知道身边有人在忙，可以偶尔抬头看一眼、放轻动作，继续自己的事。画面不表现 Agent 的工具调用、报错或完成，也不把 Vasu 画成工作进度条。
- **自己的生活**：以微呼吸、眨眼和安稳坐姿为视觉基线；观察、专注做小事、休息、睡觉和短暂玩耍是它自己的活动。玩耍不表示任务成功，失落不表示工具失败。动作有起承转合，幅度小，结束后自然安定下来。
- **朋友式回应**：被主动接近或投喂时，可以短暂回望、轻抬爪、点头或轻跃；偶尔主动示意陪伴即可，不要反复招手、索取注意或讲解用户正在做什么。安静陪伴不等于整天定格在一张待机图上。
- **辨识度优先**：无论在专注、困倦还是玩耍，始终保留主图的脸型、眼耳比例、奶油色口鼻胸腹、暖棕毛色与厚尾。情绪主要靠姿态、视线和微小表情变化，不靠夸张五官或临时道具。

## 3. 素材目录与交付边界

```text
assets/vasu/
  reference/                  已提供的三张参考图；只读身份来源
  production/                 后续阶段创建，保存 hatch-pet 工作清单与中间产物
  core/                       后续阶段创建：Codex 兼容 pet.json、spritesheet.webp
  extended/                   后续阶段创建：Coeva 专有动画，独立于 Codex 图集
  qa/                         后续阶段创建：接触表、动作预览与验证结果
```

本轮只新增此规范，不创建空占位目录、图集、动画行或安装包。未来 `core/` 的发布副本分别放入 Codex 的 `${CODEX_HOME}/pets/vasu/` 和 Coeva 的 `assets/pets/vasu/`。`extended/` 不占用 Codex 图集的 9 行。制作时以 `reference/vasu-canonical.png` 为权威，不用重新生成的 base 图覆盖身份定义。

## 4. Codex 兼容核心动画

hatch-pet 的固定图集为 1536×1872、8 列 × 9 行，每格 192×208，背景透明，未用格必须完全透明。行号、帧数与时长以 hatch-pet 的 `references/animation-rows.md` 为准；以下锁定 Vasu 的动作解释。

| 行 | 状态 | 帧 | Vasu 表达 |
| ---: | --- | ---: | --- |
| 0 | `idle` | 6 | 安静呼吸、偶尔眨眼，首帧也适合作为减少动态效果的静态形象。 |
| 1 | `running-right` | 8 | 朝右移动的自然步态；是拖拽移动语义，不是持续兴奋奔跑。 |
| 2 | `running-left` | 8 | 朝左移动；先审查第 1 行能否安全逐帧镜像。 |
| 3 | `waving` | 4 | 察觉用户靠近后用一只前爪短暂回应，随后回到自己的平静生活；不是重复招手或索取注意。 |
| 4 | `jumping` | 5 | 小幅度的自然跃起与落定，不做夸张弹跳。 |
| 5 | `failed` | 8 | Vasu 自己的小意图没有奏效后的短暂困惑或轻微失望，随后恢复平静；不表达 Agent、用户或系统失败。 |
| 6 | `waiting` | 6 | 暂时停下自己的活动，在共享空间中安静而清醒地留意周围；不等待指令或恳求关注。 |
| 7 | `running` | 6 | 为自己的小事有目的地迈步、前往自己选择的位置；短腿贴地、节奏克制，**不是** Agent 执行进度或用户工作反馈。 |
| 8 | `review` | 6 | 对共享空间里某个引起兴趣的事物保持片刻专注观察；不检查 Agent 输出或用户工作，不新增道具。 |

这些行是 Codex 兼容素材的动作词汇，并不要求 Vasu 跟随 Agent 的具体工作内容表演。各行都要保持同一只 Vasu 的脸、比例、配色和克制的动作幅度。

## 5. Coeva 专有扩展动画

扩展资产另存于 `assets/vasu/extended/`，不挤进上述九行。下一阶段的动作候选是 `sleep`（自然安睡）、`observe`（安静自主观察）、`self-work`（做自己的小事）、`play`（偶尔轻微玩耍）与 `slice-ack`（收到主动投喂切片后的轻微确认）。具体姿态与帧数留待动作设计阶段决定，本轮不制作。河流、石头与日常场景属于可选的氛围/叙事层，不成为 Vasu 的永久随身道具。

## 6. 生产风险与下一道验收门

- 主图偏正面，缺乏同等权威的纯侧面、背面和步态视图；不能直接把情绪板侧面小图当成形体标准。先审定右向侧身关键姿态，再制作或镜像方向行动画。
- 主图的轻微笑意可保留为温和基线，但不可放大为每一帧的夸张笑脸；情绪板更强的表情、道具与近似办公/程序员场景只提供语义灵感。
- 64×64 参照强调小尺寸辨识，192×208 图集允许更多细节；缩放后需同时检查眼、口鼻胸腹、短耳和粗尾是否仍清楚，并避免色阶或脸型随行漂移。
- Codex 的 `waiting`/`running`/`failed` 容易被画成恳求、忙乱或戏剧化失败；制作时把它们收敛为耐心、专注和短暂低落，保持 Vasu 的独立气质。
- `idle`、观察、专注与困倦都偏安静，若姿态差异过小会难以辨认；玩耍与回应若幅度过大，又会破坏桌面陪伴的安宁。先用动作草图确认区别与强度。

下一步先审定 Vasu 的右向站/走姿态、小尺寸像素比例，以及“观察、做事、休息、玩耍、回应”的动作草图；之后才用主图和 64×64 参照按 hatch-pet 规格制作完整的 `idle`、`running-right` 试验行。只有身份与步态试验通过后，才继续其余核心行及扩展动画。
